# 驗證記錄 — v1.0.7

- **日期**：2026-09-07
- **版號**：1.0.7（package.json + src/manifest.json + publish/*.jpl 內嵌版號，三者一致）

## 需求描述

1. 查證各大模型官方 API 端點並修正預設內容；新增 OpenAI、Claude、xAI Grok、Kimi、Qwen、Ollama（本機）六家 Provider；新增「Model（覆寫，選填）」欄位；更新過時預設模型。
2. AI 生成視窗整合改版：「整理筆記內容」與「優化我輸入的內容」合而為一；點按鈕可把當前筆記內容（選取段落優先）複製到輸入框；「生成」將輸入框內容送 LLM；結果以可編輯 Text 呈現；確認後可「覆蓋全文」或「加入末尾（最後一行）」寫入筆記。

## 變更摘要

- `src/llm.ts`：
  - 新增 `apiFormat`（openai / anthropic）：anthropic 分支走 `POST {base}/messages`、headers `x-api-key` + `anthropic-version: 2023-06-01`、system 訊息抽為 top-level `system` 欄位、回應解析 `content[].type==='text'` 串接。
  - apiKey 為空時省略 Authorization / x-api-key header（支援 Ollama 免金鑰）。
  - 預設 model 參數更新為 gpt-5.5；maxTokens 維持 4096；timeout 維持 120s。
- `src/index.ts`：
  - Provider 下拉擴充為 10 項（保留原 0-3 編號避免遷移問題，新增 4-9）：
    - OpenAI `https://api.openai.com/v1`（gpt-5.5）
    - Claude `https://api.anthropic.com/v1`（claude-sonnet-5，anthropic 格式）
    - xAI Grok `https://api.x.ai/v1`（grok-4.6）
    - Kimi `https://api.moonshot.ai/v1`（kimi-k3）
    - Qwen `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`（qwen3.7-max）
    - Ollama `http://localhost:11434/v1`（無內建模型、金鑰免填 keyOptional）
  - 現有預設更新：自訂預設 model gpt-4o-mini → gpt-5.5；Gemini gemini-2.5-flash → gemini-3.8-flash（DeepSeek/OpenCode 不變）。
  - `aiModel` 欄位語義改為「Model（覆寫，選填）」，預設值改空字串；一次性遷移清除舊預設殘留值 gpt-4o-mini。
  - 新增 6 個私有 secure slot（aiOpenaiApiKey 等）；`resolveLLMConfig()` 支援 model 覆寫、keyOptional、apiFormat；缺模型時引導至 Model 欄位。
- `src/magicWand.ts`：
  - 移除模式 radio；單一輸入框 + 單一整合提示詞（整理 + 優化合一，支援自訂指令）。
  - Phase 1 輸入框預填當前內容（選取段落優先）；Phase 2 顯示輸入內容（唯讀）+ 生成結果（可編輯）；寫入按鈕改為「取消 / 加入末尾 / 覆蓋全文」。
  - 加入末尾前重讀 note body 防競態；覆蓋全文直接 data.put。
- `src/dialog.js`（新檔）：純前端腳本（document 事件委派），提供「🔄 重新載入筆記內容」「✕ 清空」按鈕，經 `dialogs.addScript` 載入，視窗不關閉；webpack CopyPlugin 自動複製至 dist 並打包進 .jpl。
