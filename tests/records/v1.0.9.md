# 驗證記錄 — v1.0.9

- **日期**：2026-09-07
- **版號**：1.0.9（package.json + src/manifest.json + publish/*.jpl 內嵌版號，三者一致）

## 需求描述（問題回報修復）

1. 切換 Provider 時 API URL 未即時同步 — 經診斷確認為 **H1**：資料層已同步（重開設定畫面後欄位值正確），Joplin 設定畫面不會即時重繪程式寫入的欄位。修復方向：連線設定移入 Note AI 自有對話框（即時反應、不受設定畫面限制）。
2. Markdown 預覽未呈現表格 — 根因：`.md-preview` 無表格樣式（marked GFM 表格有渲染為 `<table>`，但無框線視覺上如同純文字）。

## 變更摘要

- `src/settingsDialog.ts`（新檔）：連線設定對話框 —
  - 表單：LLM Provider 下拉（10 選項）、API Key、API Base URL、Model 覆寫。
  - **前端即時行為**：烘入 escape 過的 JSON（各 provider 的 key/URL slot 值 + 內建端點），`dialog.js` 監聽 select change 立即帶出該供應商的金鑰與 URL。
  - 寫回：按「儲存」→ formData → 主程序一次寫回 provider、key slot、URL slot、`SETTING_BASE_URL`、editor 欄位、Model；「取消」不寫。
- `src/index.ts`：
  - 新指令 `noteAiSettings`「Note AI: 連線設定」+ EditorToolbar 齒輪按鈕（fas fa-cog）。
  - `buildSettingsData()` 組裝烘入資料（含 custom provider 的 URL 讀自 `aiBaseUrl` 欄位）。
  - `saveConfigSelection()` 寫回；`lastKnownProvider` 先於延遲 echo 更新（batch 歸屬值相同 → no-op 收斂，無迴圈誤存）。
  - 既有 `settings.onChange` 同步邏輯保留（H1 證實資料層正常）。
- `src/magicWand.ts`：`.md-preview` 補表格樣式（border-collapse、th/td 邊框與 padding、表頭底色）與 img max-width。
- `src/dialog.js`：新增設定對話框 select change 處理；`marked.parse(text, { gfm: true })` 明示；渲染例外改為 `console.warn`（原本靜默）。
