# 驗證記錄 — v1.0.13

- **日期**：2026-09-07
- **版號**：1.0.13（package.json + src/manifest.json + publish/*.jpl 內嵌版號，三者一致）

## 需求描述

1. 工具列圖示由魔法棒（`fas fa-magic`）改為巫師帽（`fas fa-hat-wizard`）（使用者指定）。
2. 新增 LLM API 連線測試：使用者要求「設定頁面新增按鈕，並顯示成功或失敗的原因」。
   - 平台限制（已查證）：Joplin 外掛設定區塊無法放自訂按鈕（`ConfigScreen.handleSettingButton` 僅接受內部按鈕，其他鍵拋 `Unhandled key`）→ 以「測試 LLM 連線」對話框替代，呈現連線摘要 + 測試按鈕 + 成敗結果橫幅。

## 變更摘要

- `src/index.ts`：
  - 魔法棒指令 `iconName` → `fas fa-hat-wizard`
  - 新增 `resolveTestTarget()`：不拋出例外版本的設定解析（缺 key/模型回傳錯誤訊息而非 throw），供測試對話框顯示摘要與事前檢查
  - 新增指令 `noteAiTestConnection`（label「Note AI: 測試 LLM 連線」、icon `fas fa-plug`）+ Tools 選單項目
- `src/connectionTest.ts`（新增）：
  - 對話框顯示唯讀連線摘要：Provider、端點、模型、API Key（`maskKey()` 遮罩：≤12 字元僅顯示長度、>12 顯示前4+後4）、請求格式
  - [🧪 測試連線] → 處理中畫面（spinner，視窗保持開啟，同 v1.0.12 模式）→ 送出極小請求（`maxTokens: 64`、提示「連線測試：請回覆 OK」）→ 原地換頁顯示結果橫幅
  - ✅ 成功：延遲 ms + 回覆片段（截 40 字；空回覆顯示「連線正常，回應為空」）
  - ❌ 失敗：錯誤訊息 + 檢查建議（Key／端點／模型／網路）；事前檢查（缺 key/模型）直接顯示原因不送請求
  - 可重複測試；[關閉] 結束；busy 旗標防重入；`!action` null 防護
- `src/llm.ts`：無變更（`maxTokens` 選填參數原本即支援）
