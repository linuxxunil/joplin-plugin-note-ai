# v1.0.18 驗證記錄

- **日期**：2026-09-07
- **版號**：1.0.18

## 需求描述

魔法棒結果區按鈕擺位修正（使用者回報）：

1. 「重新生成／加入末尾／覆蓋全文」放在與「回到編輯」（結果區預覽切換鈕）相同高度（同一行工具列）
2. 無需點「回到編輯」就能看到/按到這三顆按鈕

**根因**：v1.0.17 三顆動作按鈕在頁面最底部；Joplin dialog webview 外層 `html { overflow: hidden }`（UserWebviewIndex.html），當輸入區＋結果區總高超過 80vh 對話框高度時底部按鈕被裁切，需捲動或切換預覽改變高度才露出。

## 變更摘要

- `src/magicWand.ts`（僅版面與 CSS）：
  - 結果區工具列合併為一行：`[👁 預覽 Markdown／✏️ 回到編輯] [🔄 重新生成] [➕ 加入末尾] [📄 覆蓋全文]` — 預覽模式下按鈕照常顯示、照樣可按（值由隱藏 textarea 讀取）
  - 完成後階段移除底部 action bar（按鈕已上移）；生成前仍保留底部「✨ 生成」
  - 錯誤且無結果時：錯誤 banner 下方保留一行「🔄 重新生成」
  - 新增 `#joplin-plugin-content { overflow-y: auto; max-height: 100vh; }` — 內容過長時頁面可捲動，避免元素被裁切（防裁切保險）
- `src/wand.js`、`src/dialog.js`、`src/llm.ts`、`src/index.ts`：未動（按鈕 id 不變）
