- **日期**：2026-09-07

## 需求描述

1. 回退 v1.0.9 的「對話框連線設定」— 設定統一在 Joplin 設定頁配置，不在筆記/對話框新增設定入口。
2. Provider 切換時 URL 欄位未即時變動（H1：Joplin 設定畫面不會即時重繪程式寫入的欄位）— 提供按鈕手動套用端點 + 即時通知回饋。
   - 技術限制：Joplin 外掛設定 API 不支援在設定頁放置可點擊按鈕（`SettingItemType.Button` 的 `onClick` 僅供內部設定使用），按鈕改放編輯器工具列與 Tools 選單。

## 變更摘要

- **回退**：刪除 `src/settingsDialog.ts`；`src/index.ts` 移除 `noteAiSettings` 指令、工具列齒輪按鈕、`buildSettingsData`/`saveConfigSelection` 及相關 import。保留：slot 機制、onChange 資料層同步、魔法棒、Markdown 預覽與表格樣式。
- **新增**：
  - 指令 `noteAiApplyEndpoint`「Note AI: 套用所選 Provider 的 API 端點」— 入口：編輯器工具列按鈕（fas fa-sync-alt）+ Tools 選單。
  - `applyEndpoint()`：讀當前 Provider → 取端點（slot 自訂值優先，否則內建端點）→ 寫入 `API Base URL` 欄位 → Toast 顯示「已套用「{Provider}」端點：{url}」。
  - Provider 切換 Toast：onChange 自動同步後顯示「已載入「{Provider}」設定 — 端點：{url}」（即時視覺回饋；資料層本就正確）。
  - URL 欄位說明加註：顯示不會即時更新（Joplin 限制），重開設定畫面可見，或用「套用端點」按鈕。
