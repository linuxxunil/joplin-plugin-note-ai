# v1.1.2 驗證記錄

- **日期**：2026-09-09
- **版號**：1.1.2

## 需求描述

1. **修復官方外掛倉庫未更新問題**：1.1.0/1.1.1 已發佈 npm（9/7）兩天，但 Joplin 官方外掛倉庫（joplinapp.org/plugins）仍停留在 1.0.2。
2. **記錄此限制**，避免再次犯錯。

## 根因（Joplin bot 原始碼驗證）

- 1.0.2 首次收錄時 manifest 的 `repository_url` 為 `https://github.com/linuxxunil`（個人首頁），官方 `manifests.json` 以此值登記
- v1.1.0 將 `repository_url` 改為 `https://github.com/linuxxunil/joplin-plugin-note-ai`
- Joplin 官方 bot（`plugin-repo-cli`，每 30 分鐘掃 npm）的防劫持檢查（`checkIfPluginCanBeAdded.ts`）：
  `originalRepo && (!newRepo || originalRepo !== newRepo)` → throw → **該外掛更新被靜默跳過**（工作流整體照樣 success，無錯誤 commit，僅工作流 log 有 console.error）
- 驗證證據：bot 正常運作（9/8~9/9 持續收錄其他外掛更新）；`joplin/plugins` 的 `manifests.json` 中 `vip.bestsvip.note-ai` 停在 1.0.2、`repository_url` 為舊值；`validateUntrustedManifest.ts:39` 確認 npm 更新路徑經過此檢查

## 變更摘要

- `src/manifest.json`：
  - `repository_url` 還原為登記值 `https://github.com/linuxxunil`（通過 bot 檢查）
  - `homepage_url` 指向正確 repo `https://github.com/linuxxunil/joplin-plugin-note-ai`（官方清單 🏠 連結用 homepage_url，不受檢查限制）
  - version → 1.1.2
- `package.json`：version → 1.1.2
- `AGENTS.md`：新增「發佈規範」章節 — 記錄 manifest `repository_url` 不可變更（硬性規定）、靜默跳過機制、歷史案例、homepage_url 不受限、變更登記值需開 issue 請維護者處理
- `publish.md`：加 ⚠️ 提醒（repository_url 不可變更，詳見 AGENTS.md）
