# 驗證記錄 — v1.0.8

- **日期**：2026-09-07
- **版號**：1.0.8（package.json + src/manifest.json + publish/*.jpl 內嵌版號，三者一致）

## 需求描述

1. OpenCode 實際使用 OpenCode Go — 查證 Zen 與 Go 的 API URL 是否相同後修正端點。
2. 設定說明不再列示官方端點；選擇 LLM Provider 時 URL 自動填入，且支援自訂（各 Provider 分別記憶自訂值）。
3. 筆記輸入框（與生成結果區）可呈現 Markdown 渲染格式。

## 查證結果（OpenCode Zen vs Go）

- 端點**不相同**：Zen `https://opencode.ai/zen/v1`（按量計費）、Go `https://opencode.ai/zen/go/v1`（$10/月訂閱，僅開源模型）；同一把 API Key 通用。
- 本外掛改用 **Go 端點**，預設 model 改為 `glm-5.1`（Go 已確認模型清單）；其他 Go 模型（kimi-k2.5、MiniMax-M2.5/2.7、qwen3.5/3.6-plus 等）可經「Model（覆寫，選填）」欄位使用。

## 變更摘要

- `src/index.ts`：
  - OpenCode preset：baseUrl → `https://opencode.ai/zen/go/v1`、defaultModel → `glm-5.1`。
  - 新增 9 個隱藏 URL slot 設定（`aiUrlOpenai` 等；非機密，`secure: false`）；ProviderPreset 新增 `urlSetting` 欄位。
  - Provider 切換時自動載入該供應商的 **API Key + API Base URL**（slot 為空時以內建端點填入欄位）；URL 欄位編輯自動存回當前 Provider 的 slot — 切換後自訂值不丟失。
  - `resolveLLMConfig()` 一律讀取 URL 欄位值（空值 fallback 內建端點）→ 使用者自訂 URL 立即生效。
  - onChange 同步擴充：key/URL 編輯與 Provider 切換的 batch 歸歸屬（歸屬 `lastKnownProvider`）、`syncingFields` 防重入、值相同 no-op。
  - 說明文字清理：API Key 欄位與所有 slot 描述移除官方端點列示；URL 欄位說明改為「自動填入、可自行修改」。
- `src/magicWand.ts`：輸入框與生成結果區各加「👁 預覽 Markdown」切換鈕與 `.md-preview` 預覽 div（含程式碼/連結樣式）；`createMagicWandDialog` 依序 addScript `lib/marked.min.js`、`lib/purify.min.js`、`dialog.js`。
- `src/dialog.js`：新增預覽切換邏輯 — `DOMPurify.sanitize(marked.parse(text))` 渲染至預覽 div，切換按鈕面「👁 預覽 Markdown / ✏️ 回到編輯」；lib 未載入或解析例外時 no-op / 純文字 fallback（textarea 永遠可用）。
- vendor：`src/lib/marked.min.js`（marked 4.3.0 UMD）、`src/lib/purify.min.js`（DOMPurify 3.4.15 UMD），官方 npm dist 未修改；webpack CopyPlugin 自動複製進 dist 與 .jpl。
