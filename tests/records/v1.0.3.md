# 驗證記錄 — v1.0.3

- **日期**：2026-09-07
- **版號**：1.0.3（package.json + src/manifest.json 同步）

## 需求描述

1. 優化魔法棒：提供「整理當前筆記內容」與「協助使用者輸入內容並由 LLM 優化」兩種模式，LLM 結果預覽後由使用者決定是否存入筆記（取代全文 / 附加末尾 / 插入游標處 / 放棄）。
2. 設定優化：新增 LLM Provider 下拉選單（自訂 / Google Gemini / DeepSeek / OpenCode Zen），各供應商獨立 API Key 欄位；選擇供應商即自動使用其 API 端點與預設模型。
3. 修正 AGENTS.md：由 Python/pytest/VERSION 規範改為符合實際狀況（TypeScript Joplin 外掛 / NodeJS）。

## 變更摘要

- `AGENTS.md`：改寫為 NodeJS/TS 專案規範（版號於 package.json + manifest.json、驗證以 npm run dist 為基準、驗證記錄機制）。
- `src/index.ts`（新增）：
  - Provider 設定（`aiProvider`，Int + isEnum 下拉）與供應商預設表（Gemini / DeepSeek / OpenCode Zen 的 baseUrl、預設 model、獨立 key 欄位）。
  - `resolveLLMConfig()` 依 Provider 執行期解析設定；Key 缺失時給出引導性錯誤訊息。
  - 新指令 `noteAiMagicWand`（魔法棒）綁定 EditorToolbar；保留舊指令 `noteAiProcessNote` 為獨立指令。
- `src/magicWand.ts`（新檔）：兩階段對話框流程（模式選擇/輸入 → 預覽/存入決策）、整理與優化專用 system prompt、HTML escape、busy 旗標、toast 回饋。
- `src/llm.ts`：新增 AbortController 逾時（120 秒）、錯誤回應截斷（500 字）、maxTokens 預設 2048 → 4096。
