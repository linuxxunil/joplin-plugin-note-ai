# v1.0.17 驗證記錄

- **日期**：2026-09-07
- **版號**：1.0.17

## 需求描述

1. **修復 OpenCode 連線 400 錯誤**：OpenCode Go（Console Go）端點自 2026-09-07 起強制要求 `x-opencode-session` 標頭（官方文件 "Where can I use it?"；錯誤訊息 `MissingSessionID`）。並依文件建議附上自有 `User-Agent`。
2. **OpenCode 預設模型改為 `glm-5.3-flash`**（使用者指定；模型清單已更新，glm-5.3-flash 為 chat/completions 端點模型）。
3. **魔法棒單頁常駐版面**（使用者 3.1–3.4）：
   - 3.1 按生成後 AI 指令（選填）欄保留
   - 3.2 輸入內容位置保留原 layout（重新載入筆記內容、清空、預覽 Markdown）
   - 3.3 輸入內容保持可編輯
   - 3.4 重新生成以「當前輸入內容 + 當前指令」重跑

## 變更摘要

- `src/llm.ts`：
  - `CallLLMOptions.sessionId?: string`；新增 `export function makeSessionId()`（`crypto.randomUUID()` + fallback）
  - `callLLM()`：`baseUrl` 含 `opencode.ai` 時自動附 `x-opencode-session`（優先呼叫端 sessionId，否則每次呼叫自動產生）與 `User-Agent: note-ai-joplin-plugin/1.0`；openai / anthropic 兩種格式皆適用；其他 provider 不受影響
- `src/index.ts`：`PROVIDER_OPENCODE.defaultModel` `glm-5.1` → `glm-5.3-flash`
- `src/magicWand.ts`（單頁版面重構）：
  - 移除多頁式 buildInputHtml / buildProcessingHtml / buildErrorHtml / buildResultHtml，改為單一 `buildWandHtml(state)`
  - 生成後版面保留：AI 指令欄、工具列（重新載入/清空/預覽）、可編輯輸入框；結果區塊（可編輯 + 獨立預覽鈕）顯示於下方
  - 處理中：結果區塊改為 spinner（「AI 獲取中」+ 模型名），輸入框/指令轉 readonly 防止編輯遺失，action bar 隱藏
  - 錯誤：頁內 error banner（不整頁換頁），保留版面與「重新生成」
  - 「重新生成」與「生成」共用 `noteAiGenerate` id → 皆讀取當前輸入框 + 指令
  - 移除 back 事件與唯讀輸入框；寫入 fallback 改 `state.result`
  - 每次開啟產生 `sessionId`（同一對話之生成/重新生成共用，符合 OpenCode「stable session per conversation」）
  - CSS：textarea 加 max-height（28vh/32vh）、processing padding 縮小、md-preview 上限調整
- `src/wand.js`：移除 noteAiRegenerate/noteAiBack 處理；append/replace 續送當前結果值
- `src/connectionTest.ts`、`src/dialog.js`：未動（連線測試的 session id 由 llm.ts 自動產生）
