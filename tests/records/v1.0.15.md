# v1.0.15 驗證記錄

- **日期**：2026-09-07
- **版號**：1.0.15

## 需求描述

修復魔法棒「按生成後視窗關閉、無法讀取輸入內容（表單資料缺失）」問題。

**根因**（Joplin 3.6.14 原始碼驗證）：外掛 HTML 自 v1.0.7 起沒有 `<form>` 元素，而 Joplin 的表單收集（`UserWebviewIndex.js` 的 `serializeForms()`）只收集 `document.getElementsByTagName('form')`，故 `formData` 恆為空物件 `{}`，按鈕 onClick 依 `Object.keys(formData).length` 判定後不附帶 formData 關窗，導致 v1.0.7~v1.0.13 靜默失敗、v1.0.14 顯示「表單資料缺失」。另隱藏缺陷：formData 結構為 `{ 表單名: { 欄位名: 值 } }` 巢狀，原有平面讀法即使有 form 也取不到值（「可編輯結果」自 v1.0.7 起從未生效）。

## 變更摘要

- `src/magicWand.ts`：
  - Phase 1 輸入頁：`<textarea name="userInput">` + `<input name="instruction">` 包進 `<form name="noteAiInput">`
  - Phase 2 結果頁：`<textarea name="result">` 包進 `<form name="noteAiResult">`
  - 新增 `extractFormValues(formData, field)` helper，跨表單名攤平讀取；Phase 1/Phase 2 讀值改用之
  - Phase 2 replace/append 分支合併重複邏輯
  - CSS 新增 `.note-ai-wand form { margin: 0; }`
- `src/dialog.js`：新增 capturing `submit` 監聽並 `preventDefault()`，防止 form 內按 Enter 觸發隱式提交造成 iframe 導航、內容被清空（Joplin 自己的 bubble 端 submit 監聽不受影響，Enter→生成行為保留）
